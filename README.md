# CitizenCafeTechTask
Photo Carousel Viewer of pictures from my Facebook. A responsive, mobile-friendly photo carousel built with HTML, CSS, and JavaScript.

Work process:
1. Designed a mockup in Figma (loosely inspired by Citizen Café’s branding)
2. Used ChatGPT to generate the initial code based on the design
3. Studied the code thoroughly to understand how it works
4. Made improvements and adjustments (using ChatGPT and Claude)
5. Added my own comments for clarity and learning
6. Continuously tested the site throughout development

This was my first HTML project, it was a great experiance, I enjoyed it!
The carousel is working, but I know there’s room to improve! Would love to hear feedback.
